# Лабораторная работа 2: In-memory база данных

## Описание структуры проекта
Проект организован по принципу разделения бизнес-логики и интерфейса (src-layout):
* `src/db/backend/memory.py` — Слой хранения. Реализует базу данных в оперативной памяти на базе списков и кортежей, а также CRUD-операции.
* `src/db/tui.py` — Текстовый пользовательский интерфейс для взаимодействия с пользователем через терминал.
* `src/db/__main__.py` — Точка входа в приложение.

## Реализованная функциональность
Были реализованы операции управления данными:
1. **Create** — Добавление новой записи с уникальным ID и валидацией возраста.
2. **Read** — Поиск и фильтрация студентов по всем полям таблицы.
3. **Update** — Обновление данных существующего студента по ID (с сохранением неизменных полей).
4. **Delete** — Удаление записи по идентификатору.
