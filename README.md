## ## Описание структуры проекта
Проект организован по принципу разделения бизнес-логики и интерфейса (src-layout):
* `src/db/backend/database.py` — Абстрактный базовый класс, задающий общий интерфейс СУБД.
* `src/db/backend/file.py` — Реализация базы данных, которая хранит таблицы в JSON-файлах.
* `src/db/backend/memory.py` — In-memory реализация базы данных из предыдущей работы.
* `src/db/backend/table.py` — Класс таблицы, отвечающий за структуру колонок и хранение записей.
* `src/db/tui.py` — Текстовый пользовательский интерфейс с выбором типа базы данных.

## ## Реализованная функциональность
Были реализованы операции управления данными с поддержкой персистентности:
1. **Сохранение на диск** — Данные сохраняются в формате JSON в папку `data/`.
2. **Загрузка при запуске** — Программа восстанавливает состояние таблиц из файлов.
3. **Обработка ошибок** — Добавлены исключения для битых JSON-файлов и отсутствующих директорий.
4. **Полиморфизм** — Интерфейс работает одинаково как с памятью, так и с файлами.
